# Evidence and research integrity

## Separate the checks

Reference existence, bibliographic correctness, claim support, numerical reproducibility, and causal identification are different questions. Passing one does not establish the others. Do not claim that a manuscript is free of academic-integrity issues merely because its DOIs resolve.

For a citation that is new, substantively changed, doubtful, or explicitly audited:

1. Verify that the source exists using an authoritative publisher, original agency, DOI metadata, or the original paper.
2. Verify author, title, year, journal or publisher, and DOI or stable URL.
3. Read the relevant original material and locate the support for the specific claim.
4. Check the claim's population, setting, time, measurement, and strength against that support.
5. Record unresolved support separately and tell the author. Do not invent a sentence, quotation, or page location.

An abstract may establish a study's topic without supporting a detailed mechanism. A general dietary or service framework does not automatically supply a particular parameter. A review reporting associations does not establish every proposed cause.

For ordinary language polishing with unchanged claims and citations, preserve the citations; do not launch an unnecessary full literature audit. If an obvious support problem is encountered, flag it without inventing a replacement.

## Citation placement and frequency

Attach citations to the claims they support. Do not sprinkle the same citation after every sentence in a paragraph when attribution is already clear. Conversely, deleting repeated citations must not make a new claim appear supported by a source that did not address it.

Prefer a direct source for a precise statement. A source pile is appropriate for genuine synthesis, not as a substitute for explaining which study established what. Use a study's location only when it matters to the argument, not as decorative shorthand.

For the same article, reconcile different cached author labels through the reference manager and its authoritative item metadata. Do not change displayed text alone while leaving a contradictory underlying citation field.

## Zotero and managed Word citations

When managed citations are in scope, use the available Zotero workflow for inserting, correcting, and refreshing citations and the bibliography. Preserve native citation fields and the item mapping. Do not flatten a document or replace managed fields with manually typed author–year text simply to make the display look correct.

Before changing bibliography output, distinguish item metadata, citation-style behavior, and a stale field cache. Extraneous archival or citation-count metadata should be fixed at the appropriate source or style layer. Legitimate archival information must not be removed indiscriminately from actual archival sources.

A document-level correction does not authorize global changes to all APA styles or all Zotero items. Back up or use a separately named style when appropriate, and obtain authorization before overriding shared settings. If Zotero integration is unavailable, report that limitation rather than claiming a native refresh succeeded.

## Parameter and result provenance

For a numerical reference point, retain the exact value, units, population, source, and derivation. Distinguish a recommended target, upper limit, range, selected midpoint, conversion, and analyst-chosen anchor. If daily quantities are converted to energy densities, preserve the energy denominator and conversion rule.

If an old script only hard-codes a number, do not retroactively invent the reason it was chosen. A numerical resemblance to a guideline is not proof of historical provenance. Explain the evidence gap to the author and agree the treatment before revising the method or rerunning the analysis.

Main text may be concise, but necessary detail must remain in the supplement, repository, or another appropriate accessible record. Omitting values to discourage criticism is not an acceptable substitute for documenting them.

When two result versions differ, identify the run corresponding to the current analysis. Confirm sample, filtering, weights, thresholds, population composition, and configuration. Do not choose the newer file by date alone or the more favorable result by magnitude.

If the selected results change, check every dependent abstract, result paragraph, figure, table, caption, supplement, highlight, and response. Preserve the existing plotting code when asked to update values only. Confirm the actual input matrix and configuration; a Python file with a plausible name is not enough to prove a heatmap's origin.

## Avoid category errors

- Recorded review mentions can be a behavioral signal without being a verified purchase frequency.
- User perceptions, observed physical conditions, and independently measured performance are different evidence types.
- Area-level quality and the quality of every establishment in that area are not interchangeable.
- A generic price screen is not a household-specific affordability estimate.
- A reachable opportunity is not observed use or a realized welfare benefit.
- Repeated area-level observations are not automatically a panel tracking the same establishments or individuals.
- Repeated model runs assess repeatability; agreement across models does not by itself establish accuracy.
- Agreement with a published reference estimate is not automatically validation against laboratory or transaction ground truth.

Choose wording that accurately names the available evidence, not a repeated disclaimer that overwhelms the argument.

## Author-facing reporting

Separate **verified**, **not verified**, and **requires an author decision**. Never claim to have opened a source, refreshed Zotero, inspected every page, run a model, or checked a matrix unless that operation was actually completed.

Respect a narrowed request to ignore earlier issues during a particular comparison. State what the new check establishes; do not imply the excluded evidence issues were fixed.

## Metadata and attribution details

Use the source's actual author/byline and publication year. A government host is not automatically the named author, and a retrieval year or current website footer is not automatically the publication year. Keep publication, revision, online-first, and access dates distinct where relevant. A changed web page may require checking the actual version used.

Two author labels for the same DOI can reflect duplicate items, a group-author convention, or a stale citation cache. Inspect the actual item and authoritative record before deciding. Correct the intended managed item and refresh affected fields when authorized; do not merely change one visible occurrence.

If full text or a precise supporting passage cannot be obtained, report that specific check as incomplete. It is not proof that the source is fictitious, and a resolving DOI is not proof that the detailed claim is supported. Do not replace an uncertain source with another merely plausible citation.

## Citation-style repairs

For an APA-style display problem, inspect the rendered unwanted text, item metadata, active style identifier, and relevant CSL call. Unwanted citation counts or archive text can arise from metadata rather than repeated citation fields. Changing a macro definition without checking its invocations may leave an invalid style.

Validate CSL/XML and test a small relevant bibliography after an authorized style change. Avoid invalid nested XML comments, accidental changes to other item types, and indiscriminate deletion of legitimate archival-source information. A request to repair one document does not authorize replacing every installed APA variant. A user may explicitly authorize that broader override; keep a recoverable copy and verify the actual scope if doing so.

## Linked result versions and graph inputs

Before replacing a conflicting percentage, establish its analysis run, denominator, geography, time coverage, filters, weights, and threshold conditions. Matching the current manuscript's main analysis takes priority over choosing the newest timestamp. If it changes a substantive conclusion or requires rerunning the experiment, communicate that before broad synchronization.

For LLM comparison figures, trace the displayed matrix to the input file, model identifier/version, prompts/configuration, sample, repeated runs, and statistic. Check labels and diagonals against that provenance. A nearby Python script establishes a possible workflow, not proof that its defaults generated the current figure.

When synchronizing is authorized, inspect every dependency actually affected, including the manuscript, SI, figure values, tables, captions, highlights, letters, and an authorized repository. Keep existing plotting code and styling when instructed; record a necessary change rather than silently redrawing the figure.
